Hakkımda

Tekirdağ Namık Kemal Üniversitesi Bilgisayar Mühendisliği 4. sınıf öğrencisiyim. 3,44 genel not ortalamamla sürdürdüğüm eğitimimde algoritma tasarımı, sistem mimarisi ve yazılım prensipleri alanındaki bilgilerimi pratik projelere dönüştürüyorum. React ile kullanıcı arayüzleri, Java ve Spring Boot ile backend uygulamaları geliştirerek full-stack projeler üzerinde çalışıyorum.

Yongatek Microelectronics'teki yazılım geliştirme stajımda uydu ağlarındaki paket akışlarını görselleştiren bir simülasyon ve servis konfigürasyonlarını izleyen bir dashboard geliştirdim. React, JavaScript ve TypeScript ile edindiğim deneyimi analitik problem çözme yaklaşımımla birleştiriyor; yeni teknolojileri öğrenerek farklı yazılım geliştirme süreçlerine katkı sağlamayı hedefliyorum.

Helpdesk ve Ticket Yönetim Sistemi

Uydu Ağlarında Paket Akış Simülasyonu

ReactJavaScriptHTML/CSSSVGWireshark CSV

Yongatek Microelectronics stajımda, Wireshark CSV çıktılarındaki ağ paketlerini görselleştiren interaktif bir uydu haberleşme simülasyonu geliştirdim. İki IP adresi arasındaki RTP/SIP trafiğini filtreleyerek paket hareketlerini zaman çizelgesinde animasyonlarla gösterdim.
